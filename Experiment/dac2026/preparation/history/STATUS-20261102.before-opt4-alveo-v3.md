## FPGA 只读观察和边界

2026-11-02 的最终静态观察：

- `0000:e2:00.0` → `xdma0`，`0000:21:00.0` → `xdma1`；vendor/device `10ee:903f`，subsystem `0007`，均绑定 XDMA。
- 两张卡均发现既有 `FireSim-xilinx_alveo_u280` 进程，PID 1970507 / 2861930；既有 manager PID 1967655。
- 10:20 的 completion-check 又观察到 manager PID 3181869；该快照共4个相关进程，仍为 BUSY。本工具没有启动这些进程。

## 逻辑配置与实际缺项

| 配置 | 已交付 | 仍阻断正式运行 |
|---|---|---|
| B | 真实无保护定义、公共 baseline 身份/分析规则 | 缺与 EC BOOM/cache 同参数且真正无保护的目标 RTL；移除 WithGHE 不足以成为 B |
| D2/D4/D8 | 独立候选配置、历史 D 输入定位 | 历史 D 的 BOOM/L2 不同；需要匹配 ParaMedic/cache 并证明只检错语义 |
| C2/C4/C8 | 当前 C 的结构/频率/cache 候选 | 尚未移植并构建到独立 FireSim；N=8 的 3-bit hart/target/control 编码不能仅改核数 |
| C4-no-real-barrier | 一项真实诊断开关 `GH_REAL_BARRIER_ENABLED=false` | 需构建、确认输出及实际覆盖路径；保护能力削弱，不是 D，差值不能加总成独立贡献 |

7 个主逻辑配置 + 1 个诊断配置；已认证实验 bitstream **0**；正式准入 benchmark **0**。
这不是“0 个缺失样本”或“实验成功”。D4/C4 的一次数据在默认实验和数量扫描中复用。
运行时 mask/功能切换等价性未验证，当前不假定可复用 bitstream。

共同候选：1 BOOM，应用线程1，BOOM/uncore 200 MHz，Rocket 100 MHz，ParaMedic
