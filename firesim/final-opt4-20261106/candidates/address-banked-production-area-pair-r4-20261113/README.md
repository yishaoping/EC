# Production R5 host area continuation

This immutable successor preserves the original two-thread serial OOC mapper,
resource guard, completed-checkpoint compatibility test, and live-map exclusion.
It binds the corrected precise PeekPoke observation-boundary validator R5.

CAD requires R1's full 6,144-edge, 5,684-observation target regression and invalid
payload mutation, R5's 3,003-token Plain/Threaded production host oracles and
both negative checks, all pinned bytes, and release of R5's exact cgroup.
The generated Plain and Threaded hosts have 52 public outputs and no private
proof channels; production geometry stays 16 banks, 16 lanes, 256 slots.

The experiment/controller commit is separate from hardware commit
4b0ca01ee8704fe1db70e35c08ab3bd4c00e9ec0 and functional baseline
8491167d84b6d9521b151a743673c1516926a1f8. The previous area waiter exited
without starting CAD when R2's token oracle failed; it is never restarted.

This pair measures only complete production AddressStats generated-host OOC
area. It does not admit whole EC, shell FIT, physical implementation, or FPGA IO.
