# Exact common-host offline ABI/software successor

Adopt the sole bcd4063 complete-source generation/8192-cycle DCache validator
only after its material gates, PASS receipt and exact cgroup release. This job
does no generation, simulation, CAD, runtime launch or FPGA operation. It leaves
the 3656 runtime and every pinned live input untouched.

Bind the exact hardware commit, separately recorded controller commit, source
variant, all successful stage logs/outputs, host RTL, frozen parameters and seven
generated files to a fresh host identity. All five software ABI files must match
the authenticated parent byte-for-byte for offline driver reuse. Both constraint
files are accounted for independently and require new shell/physical validation;
byte equality is never a timing/placement certificate. A changed software ABI
retains a rebuild-required result and never relabels the old driver as compatible.

Authenticate prepared binaries, initramfs payload hashes and firmware build
outputs for the eight requested programs. Do not inspect or export historical
CPU/SVB/runtime measurements. Preserve first-ready program order. The driver is
copied to a private offline directory only after exact ABI equality and is never
executed. No runtime bundle, certificate, handoff or device admission is created.

Preflight uses actual archived generated files and software build outputs, then
mutates header/constraint bytes and identity fields to check rejection and scope
handling. These checks do not validate the future common-source generated host.
That host still needs complete tokens, exact full-shell area, physical timing,
DRC, bitstream authentication, new runtime binding and real FPGA samples.
