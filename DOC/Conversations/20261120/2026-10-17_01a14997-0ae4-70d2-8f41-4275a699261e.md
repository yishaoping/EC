## 关键实现与语义

### ImageKey / 统一 gate

新增：

`chipyard/generators/rocket-chip/src/main/scala/tilelink/CacheImage.scala`

- `CacheImageKey`：`valid:Bool, writer:16, generation:32, contentSeq:32`，地址由 transaction 地址/directory tag 携带。
- `valid=false` 且全零是 BASE coherent lower image，不表示 L1 slot invalid。
- 实际本地写，包括 seq=0 可信写，都生成 valid=true 的全局本 writer serial。
- `CacheImage` 为 TL `ControlKey`，`CacheImageField` 提供默认零。
- `CacheImage.base(TLBundleA/C)` helper：初始化 TLEdge 构造函数没有填的 optional user field。

`boom/.../lsu/phase1.scala`

- install 新增 `image`、`has_data`；refill 新增 `image`。
- `L1Preservation.safe(key,wm)`：BASE 或 seq0 或 seq<=functional watermark。
- `allow(present,key,lower,incomingSeq,wm)`：
  - 无旧 image，或同一个非零包，直接允许；
  - 否则必须 old safe，且若 incomingSeq 非零必须 lowerPreserved。
  - seq0 不能覆盖 unsafe old。
- `copyAllowed`：无 old、准确相同 key，或 old safe 且已保存。

### L1

主要文件：

`chipyard/generators/boom/src/main/scala/lsu/dcache.scala`

- BOOM node 请求 `CacheImageField` / 接收 `CacheImage` response key。
- module require 字段协商存在；writer 使用 static metadata tile ID。
- 每 slot：`imageKey`、`lowerPreserved`；`imageValid` 表完整 image presence。
- `safePacketWatermark` 移到早处，供 refill gate 使用。
- `residentCoh` mirror metadata，以实际权限生成 T→N/B→N。
- S2 同一 predicate 覆盖 normal hit、permission miss admission、replay。
- replay 被 gate 阻塞时返回 tagged `CacheTerminal.retry`，不 pop RPQ/free SDQ；S3 physical effect 再检查同一 predicate。
- SC failure 无 physical effect、不生成 key；AMO/成功 SC 和普通写同一实际 data port。
- 每 semantic write 更新 serial/key，清 receipt；dirtyPacketSeq/Tracked 改为准确 attribution，包含 seq0，去掉 sticky/max。
- shadow coordinator：
  - freeze/drain 后取最终 snapshot（允许 freeze 前 S3 先完成）。
  - old safe 才发完整 ReleaseData。
  - 仅准确 WB done key+epoch 后为仍匹配 resident 设置 receipt。
  - 同拍 probe invalidate 不设 receipt。
  - 等 probe 同 set 完成才 metadata clear，避免 resurrect。
  - clear 撤销 presence/receipt、推进 epoch，然后 refetch/retry。
- refill：
  - install `copyAllowed`，保存 installed image key。
  - 每 row 检查 owner/txn/epoch/key 和 copy gate。
  - 最后一 row fire 原子提交传入 key、presence、lowerPreserved=true。
  - no-data permission Grant 保持原 key/receipt。
  - 非法同址不同 key 覆盖未保存 old 会 fail closed/assert。
- WB：
  - 原 data FSM 的 s_grant 被独立 `ackPending/allSent/acked/pendingKey/pendingEpoch/pendingIdx` 替代。
  - C last 后 data FSM idle，可服务 probe；voluntary source 不到 ACK done 不复用。
  - parent 收 D 时核对 ReleaseAck/source/!denied/完整 pending key；过期不同 key 被消费但不推进。
  - done 在 allSent && acked 后给出 key/epoch。
  - pending index 纳入新 miss/refill hazard 和退出观察。
- fence `ordered` 纳入 WB data/pending ACK 和 shadow pending。
- 新 `STAGE2_TX`：BLOCK、PRESERVE、ACK、PRESERVE_DONE、IMPORT、MODIFY。
- 原 Stage 1 trace/owner/terminal 基础设施保留。
- 原统计 CAM 保留，L2 已不拿它做功能 provenance。

`boom/.../lsu/mshrs.scala`

- first Grant 固定完整 incoming key；后续 beats 必须一致。
- 检查 BASE 全零、authored generation!=0、Grant 不 denied/corrupt。
- install/refill 传递 key；no data Grant 不写 rows。
- 初始化 Acquire/Get/Put/AMO 的新 control 字段，避免 FIRRTL 未初始化。
- Prefetch reacquire 重置 grantFirst。

### 4. Preservation invariant 的当前实现

实际 predicate 位于 [phase1.scala](/data1/gzh/EC/chipyard/generators/boom/src/main/scala/lsu/phase1.scala:69)：


同包使用完整 32-bit package sequence；STQ 捕获后随 MSHR/RPQ 保留。当前单 BOOM、sequence 不回绕的协议下，没有发现不同动态包误判为同包的路径。

```text

→ source/full key/snapshot epoch/resident 匹配
```


地址由 header/tag/set 携带；snapshot epoch 另约束 slot 生命周期。BASE 全零 key 与 L1 slot 无效不是同一含义。

### 6. `lower_preserved` 生命周期

- **creation/reset：** false，`imageValid=false`。
- **set：** 完整 refill 最后 row 实际 fire；或 snapshot completion 经完整 key、epoch、resident 匹配且未被同拍 probe 撤销。
- **held：** validation、measurement reset、普通 stall/retry、读、无数据权限转换、SC fail 不改变 receipt。
- **cleared：** 每次真实语义写分配新 generation 并清零；invalidate/shadow clear 撤销 presence 和 receipt。
- **reuse：** 新 owner 等旧 WB/ACK 排空；最后 refill row 原子安装 incoming key/epoch/receipt，不继承旧 generation 的 receipt。
- **response matching：** 唯一 pending voluntary source、C 已全部发送、ReleaseAck 类型/size、完整 key、无 denied/corrupt；completion 再检查 snapshot epoch。

合法延迟响应由独立 pending descriptor 保存。协议不承诺 generation/epoch 回绕、非协调局部 reset 或多 BOOM namespace；当前有耗尽断言。
