## 关键波形/指令迹象

生成的 ELF 已确认 `main()` 调用：

```asm

```

`main()` 后续流程是：

1. 执行最大规模 GAPBS BFS；
2. 发出 `ROCC_INSTRUCTION_S(..., 0x02, 0x70)`；
3. 等待 26 个 NOP；
4. 发出 `ROCC_INSTRUCTION(..., 0x32)`；
5. 循环等待 `ght_get_status() >= 0x1FFFF`；
6. 才会打印 GAPBS 结果并执行 `test_report()`。

超时时，BOOM 和多个 checker 都仍在执行软件地址 `0x80002cda` 附近的 `memcpy()`：

```asm
0x80002cda <memcpy>:
0x80002cde: lb   t2, 0(a1)
0x80002ce2: sb   t2, 0(t1)
0x80002ce6: addi a2, a2, -1
0x80002ce8: addi t1, t1, 1
0x80002cea: addi a1, a1, 1
0x80002cec: bnez a2, 0x80002cde
```

最后阶段的 `a2` 值在持续递减，例如：

- BOOM `C:0` 的 `a2` 从约 `0x8ac` 下降到约 `0x88b`
