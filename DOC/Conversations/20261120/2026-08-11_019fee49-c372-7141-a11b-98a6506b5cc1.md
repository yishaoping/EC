
并将 SFC 参数改为该变量。

### 4. black-box 路径重复

现象：

```text
.../gen-collateral/.../gen-collateral/ClockDividerN.sv
```

根因：firtool filelist 已包含绝对或带 `gen-collateral` 的路径，Make 又添加一次前缀。

修复：

```make
$(SED) -e 's;^\./;;' \
  -e 's;^.*$(GEN_COLLATERAL_DIR)/;$(GEN_COLLATERAL_DIR)/;' \
  -e '\|^/|! s;^;$(GEN_COLLATERAL_DIR)/;'
```

同时 `--output-annotation-file` 改为 barstools 实际消费的：

```make
--out-anno-file
```
