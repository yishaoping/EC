## 违反的 spec/v2 invariant

主要违反：

1. **Redirect target identity invariant**

   redirect 当拍禁止请求后，下一拍必须接受同一 redirect target。当前 target 未锁存，被旧 `s2_replay/s2_pc` 覆盖。

2. **Request owner/PC identity invariant**

   S1/S2 请求必须使用同一请求的 PC、TLB response、ICache response。当前 redirect bubble 后旧 S2 owner/replay 状态继续影响新请求。

3. **Forward progress invariant**

   正常控制流 redirect 后必须到达 target。当前直接跳过必要初始化指令并进入异常循环。

4. **Exception lifecycle/admission invariant**

   producer 可以在 checker trap loop 中分配 seq=1，但 checker admission 又以 `!excpt_mode` 拒绝初始 DATA，没有可证明的 pending/admission 路径使 package 在 trap 状态下继续启动。

5. **Package lifecycle closure**

   seq=1 已由 BOOM 取得 ownership，但 checker 侧 `package_seq_reg` 仍为 0，导致：

   ```text
   BOOM owner established
   -> checker owner never established
   -> no result
   -> no release
   ```
