核心设计：

1. **只在架构提交时分配 token**  
   不再在地址生成阶段设置普通 store 的严格资格。token 至少包含窗口 epoch 和单调递增 store ID，不能只用 `stq_idx`。

4. **LSU 用 outstanding token 表消费一次**

5. **traffic reset 使用 epoch 隔离旧请求**  
   reset 后旧 MSHR replay 到达时自动失效，避免污染新统计窗口。

- underflow 时饱和为零；
- 按 `stq_idx` 去重；
- 按地址或 packet sequence 去重；
- 将完成点简单改成 MSHR 接受点。

Store 回收路径：

```scala
clear_store := Mux(
  stq(stq_head).bits.uop.is_fence,
```

## 当前修复方案

核心原则：**物理 completion 已经确认某个严格 Store 完成后，必须同步推进 `stq_execute_head`，然后才允许该 Store 被回收。**

在 completion 接受逻辑中：

当前错误在：


- 保留 checker 的 `safePacketWatermark`，继续用于跨包缓存屏障；

```text
addressStatsSafeWatermark =
    min(checkerSafeWatermark, boomCommitSafeWatermark)
```

只有当两个条件都满足时，某个包才可被回收和判定为过期。
